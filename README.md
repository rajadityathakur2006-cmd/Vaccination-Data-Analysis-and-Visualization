# 💉 Vaccination Data Analysis and Visualization

A comprehensive Exploratory Data Analysis (EDA) project focused on vaccination datasets to uncover trends, patterns, and insights using Python and SQL.

---

## 📌 Project Overview

This project analyzes vaccination-related datasets using data cleaning, exploratory data analysis, SQL, and visualization techniques. The objective is to understand vaccination coverage, introduction timelines, incidence rates, and immunization schedules through meaningful visualizations and statistical analysis.

---

## 🎯 Objectives

- Clean and preprocess vaccination datasets.
- Perform Exploratory Data Analysis (EDA).
- Identify vaccination coverage trends.
- Analyze incidence rates and vaccine introduction timelines.
- Create informative visualizations.
- Design a relational database schema using SQL.

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/rajadityathakur2006-cmd/Vaccination-Data-Analysis-and-Visualization.git
```

2. Navigate to the project directory

```bash
cd Vaccination-Data-Analysis-and-Visualization
```

3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl jupyter
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open

```
Vaccination_EDA_Capstone.ipynb
```
